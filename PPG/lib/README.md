# PPG KiCad library

Project-local libraries, wired in `sym-lib-table` and `fp-lib-table`.

- Symbols: `PPG.kicad_symdir/`
- Footprints: `PPG.pretty/`

| Symbol | Footprint | Notes |
|--------|-----------|-------|
| `PadPlaceholder_8CH` | `PadPlaceholder_8CH` | Channel pads 1–10, plus EchoCarrier bond pads 11 TX, 12 RX, 13 AE, 14 GND and six NPTH mounting holes. Not in the BOM. |

Open `PPG.kicad_pro` before editing symbols or footprints so KiCad uses these tables.
